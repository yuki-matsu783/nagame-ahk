# nagame-ahk

Windows のタスクトレイに常駐し、ホットキーやファイルを開く操作をきっかけに、いくつかの便利な
自動化・通知を行うツールです。

このドキュメントは、配布された **exeファイル（`nagame-ahk-vX.Y.Z.exe`）を使うユーザー向け**です。
開発に参加する場合は [DEVELOPERS.md](DEVELOPERS.md) を参照してください。

## 入手方法

開発者から配布される `nagame-ahk-vX.Y.Z.exe`（社内ファイルサーバー経由で配布）を受け取ってください。
exe単体で動作するため、別途 AutoHotkey本体をインストールする必要はありません。

## 使い方

exeファイルをダブルクリックすると起動し、タスクトレイに常駐します。以降は特に操作しなくても、
後述の3つの監視機能が自動的に動作します。

## トレイメニュー

タスクトレイのアイコンを右クリックすると、以下のメニューが表示されます。

| メニュー項目 | 内容 |
|---|---|
| 操作状態表示 | マウス・キーボードを操作しているか（アクティブ）／一定時間操作していないか（非アクティブ）を、カーソル付近のツールチップに表示するかをON/OFF切り替え |
| 外部コマンド受付 | 後述の「外部コマンド受付」機能のON/OFF切り替え |
| Office監視 | 後述の「Office監視」機能のON/OFF切り替え |
| PDF監視 | 後述の「PDF監視」機能のON/OFF切り替え |
| 最近使ったファイル通知 | 後述の「最近使ったファイル通知」機能のON/OFF切り替え |
| 再読み込み | アプリを再起動する |
| 終了 | アプリを終了する |

現在ONになっている機能にはチェックマークが付きます。

## ホットキー

| ホットキー | 内容 |
|---|---|
| `Ctrl+Alt+A` | 「操作状態表示」のON/OFFを切り替える（トレイメニューと同じ操作） |
| `Ctrl+Alt+N` | 動作確認用のサンプルです。ログに記録されるのみで、画面上には何も起こりません |

## 常駐機能

以下の3つは、起動すると自動的に有効になります（不要であれば上記トレイメニューから個別にOFFに
できます）。

### 操作状態表示

マウス・キーボードを実際に操作しているかどうかを、カーソル付近のツールチップに
「アクティブ」/「非アクティブ」として常時表示します。既定では3秒以上操作が無いと
「非アクティブ」と判定されます。

### Office監視

Word / Excel / PowerPoint / Visio でファイルを開くと、画面右下のトレイ通知（TrayTip）で
そのファイル名・保存先パス・開いているプロセスの情報を表示します。誤って想定と異なるファイルを
開いてしまった場合の早期発見や、ネットワークドライブ上のファイルパスの確認に使えます。

### PDF監視

以下のいずれかのPDFリーダーでファイルを開くと、Office監視と同様にファイル名・保存先パス・
プロセス情報をトレイ通知で表示します（ブラウザ内蔵のPDFビューアは対象外です）。

- Adobe Acrobat Reader / Adobe Acrobat
- SumatraPDF
- Foxit Reader

### 最近使ったファイル通知

ファイルの種類・アプリを問わず、エクスプローラー等から「開いた」ファイルを軽量にトレイ通知します
（Windowsの「最近使った項目の記録」機能を利用しています）。

> **注意**: Windows側で「スタートまたはタスクバーのジャンプリストに最近開いた項目を表示する」設定
> がOFFになっている環境では、この機能は動作しません。OFFになっている場合は起動時に一度だけ
> 警告のトレイ通知が表示されます。

Office/PDFファイルを開いた場合は、この通知とは別に上記のOffice監視・PDF監視の詳細な通知も
表示されます（連動はしていないため、2つ通知が出るのは仕様です）。

## 外部コマンド受付（上級者・自動化向け）

Python等の外部プロセスから、ウィンドウ操作・入力操作・クリップボード操作・通知表示などを
呼び出せる機能です。トレイメニュー「外部コマンド受付」で有効/無効を切り替えられます
（既定で有効）。通信プロトコルの詳細は
[docs/spec/external-command-server.md](docs/spec/external-command-server.md) を参照してください。

## ログ

動作ログは `nagame-ahk.log`（exeファイルを置いたフォルダの1つ上の階層）に出力されます。
うまく動かない場合の調査に利用してください。

## 終了方法

タスクトレイのアイコンを右クリックし、「終了」を選択してください。
